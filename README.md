# JAPAN INTER TRADING ホームページ

JAPAN INTER TRADING株式会社の公式ホームページ（WordPressテーマ）

## 概要

このリポジトリは、JAPAN INTER TRADING株式会社の公式ホームページのWordPressテーマです。

## ディレクトリ構造

```
jit-wp/
├── jit/                    # WordPressテーマディレクトリ
│   ├── css/               # スタイルシート
│   ├── js/                # JavaScriptファイル
│   ├── img/               # 画像ファイル
│   └── *.php             # テンプレートファイル
├── docker-compose.yml      # Docker設定
└── README.md              # このファイル
```

## 主な機能

- カスタム投稿タイプ（ニュース、商品）
- カスタムタクソノミー（カテゴリー、原産国、ブランド）
- インタラクティブな世界地図（事業内容ページ）
- Salesforce Web-to-Lead連携（お問い合わせフォーム）

## 開発環境

Docker Composeを使用して開発環境を構築できます。

```bash
docker-compose up -d
```
